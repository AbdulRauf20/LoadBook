# LoadBook
LoadBook is an offline-first load distribution and payment management system designed for mobile balance and easyload distributors managing transactions across multiple retail shops. It digitizes traditional bookkeeping by providing centralized customer management, quick load entry, partial and complete payment tracking, outstanding balance management, daily financial summaries, transaction history, and WhatsApp-based payment reminders.

The system is designed for fast, reliable day-to-day operations, with local data storage for offline access and cloud synchronization when an internet connection is available. Its goal is to reduce manual bookkeeping, minimize accounting errors, save time, and provide a simple digital workflow for managing daily load distribution and collections.
